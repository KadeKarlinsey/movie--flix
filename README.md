# MovieFlix (Netflix-style site)

1. Get a free key at https://www.omdbapi.com/apikey.aspx
2. Paste it into `config.js` (OMDB_API_KEY)
3. Open `index.html` in your browser (no install or build needed)

Files: index.html (page shell), style.css (styles), config.js + api.js (JavaScript, OMDb API),
components.js + pages.js + app.js (React: UI pieces, pages, router).
